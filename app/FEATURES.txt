Stripe Webhook Events
Event | DB Action
checkout.session.completed | Upsert subscription, set status=active, store plan_slug
customer.subscription.created | Upsert subscription row
customer.subscription.updated | Update status, current_period_end, cancel_at_period_end
customer.subscription.deleted | Set status=cancelled
invoice.payment_succeeded | Update last_payment_date, clear failures
invoice.payment_failed | Increment failure count, set past_due
payment_intent.payment_failed | Update transactions.status=failed

Idempotency
All webhook events checked against app.processed_events(id). Duplicates return 200 with { idempotent: true }.

Database Objects
- app.plans - 6 seeded plans with features JSONB arrays
- app.subscriptions - linked to users via plan_slug
- app.user_entitlements - view resolving effective plan with free fallback
- app.processed_events - webhook idempotency
- public.user_entitlements - public view with security_invoker
